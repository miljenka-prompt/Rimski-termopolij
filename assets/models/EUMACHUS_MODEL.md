# Eumachus human mesh

`eumachus-human.glb` is a locally served, rigged MakeHuman / MPFB2 base mesh.
It was derived from the CC0 `parametric-base.glb` published in the
`nirholas/three.ws` repository under `avatar-sources/anny`.

For this interpretation, masculine, age and facial morphs were baked into the
geometry and the unused morph targets were removed for mobile delivery. The
Roman tunic, pose, placement and subtle gesture are authored by this project at
runtime.
