# Rimski-termopolij
Rekonstrukcija rimskog termopolija iz 1 st.n.e.

## Prostorni WebAR

`spatial.html` otvara markerless prostorni prizor. Korisnik usmjerava kameru prema podu i dodirom postavlja termopolij u svoj prostor. Prizor koristi izvorni video `assets/Termopolij_svađa1.mp4` zajedno s cijelim govorom i ambijentalnim zvukom.
