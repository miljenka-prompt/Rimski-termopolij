# Carnuntum · Živi termopolij

Trojezična interpretativna WebAR rekonstrukcija prostora za hranu i piće u kontekstu rimskog Carnuntuma.

## Prostorni WebAR

`spatial.html` otvara markerless prostorni prizor. Korisnik usmjerava kameru prema podu i dodirom postavlja termopolij u svoj prostor. Prizor koristi izvorni video `assets/Termopolij_svađa1.mp4` zajedno s cijelim govorom i ambijentalnim zvukom.

`marker.html` čuva izvornu AR verziju s Hiro markerom, a `index.html` služi kao HR/EN/DE javna projektna i interpretacijska stranica s izvorima.
